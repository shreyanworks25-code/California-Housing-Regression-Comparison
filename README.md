# California Housing Price Prediction

## Project Overview

This project compares three machine learning regression models on the California Housing dataset.

### Models Used

- Linear Regression
- Ridge Regression
- Decision Tree Regression

### Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Joblib

### Evaluation Metrics

- RMSE
- R² Score

### Results

| Model                    | RMSE       | R² Score   |
|                          |            |            |
| Linear Regression        | 0.7456     | 0.5758     |
| Ridge Regression         | 0.7456     | 0.5758     |
| Decision Tree Regression | **0.7030** | **0.6228** |

### Best Model

Decision Tree Regression
